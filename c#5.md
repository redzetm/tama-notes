## LINQ

### LINQ とは

LINQ は、並んだデータから必要なものを探したり、しぼったり、形を変えたりするための書き方です。  
ここでは「一覧を相手にする便利な道具」と考えれば大丈夫です。

```csharp
using System;
using System.Linq;

class Program
{
    static void Main(string[] args)
    {
        Console.WriteLine("LINQ は並んだデータを扱う道具です");
    }
}
```

出力イメージ：

```text
LINQ は並んだデータを扱う道具です
```

### using System.Linq

LINQ を使うには `System.Linq` を読み込みます。

```csharp
using System;
using System.Linq;

class Program
{
    static void Main(string[] args)
    {
        Console.WriteLine("System.Linq を使います");
    }
}
```

出力イメージ：

```text
System.Linq を使います
```

### Where

条件に合うものだけを取り出すときは `Where` を使います。

```csharp
using System;
using System.Linq;

class Program
{
    static void Main(string[] args)
    {
        int[] numbers = { 1, 2, 3, 4, 5, 6 };

        var evens = numbers.Where(n => n % 2 == 0);

        foreach (int number in evens)
        {
            Console.WriteLine(number);
        }
    }
}
```

出力イメージ：

```text
2
4
6
```

### Select

各要素を別の形に変えるときは `Select` を使います。

```csharp
using System;
using System.Linq;

class Program
{
    static void Main(string[] args)
    {
        int[] numbers = { 1, 2, 3 };

        var squares = numbers.Select(n => n * n);

        foreach (int square in squares)
        {
            Console.WriteLine(square);
        }
    }
}
```

出力イメージ：

```text
1
4
9
```

### OrderBy

並び替えたいときは `OrderBy` を使います。

```csharp
using System;
using System.Linq;

class Program
{
    static void Main(string[] args)
    {
        int[] numbers = { 30, 10, 20 };

        var sorted = numbers.OrderBy(n => n);

        foreach (int number in sorted)
        {
            Console.WriteLine(number);
        }
    }
}
```

出力イメージ：

```text
10
20
30
```

### FirstOrDefault

最初の1つだけほしいときは `FirstOrDefault` を使います。  
見つからないときは、その型の最初の値が返ります。

```csharp
using System;
using System.Linq;

class Program
{
    static void Main(string[] args)
    {
        int[] numbers = { 3, 5, 8, 10 };
        int firstEven = numbers.FirstOrDefault(n => n % 2 == 0);

        Console.WriteLine(firstEven);
    }
}
```

出力イメージ：

```text
8
```

### Any

ひとつでも条件に合うものがあるか調べるときは `Any` を使います。

```csharp
using System;
using System.Linq;

class Program
{
    static void Main(string[] args)
    {
        int[] numbers = { 1, 3, 5, 8 };

        Console.WriteLine(numbers.Any(n => n % 2 == 0));
    }
}
```

出力イメージ：

```text
True
```

### Count

条件に合うものが何個あるかを数えるときは `Count` を使います。

```csharp
using System;
using System.Linq;

class Program
{
    static void Main(string[] args)
    {
        int[] numbers = { 1, 2, 3, 4, 5, 6 };

        Console.WriteLine(numbers.Count(n => n >= 4));
    }
}
```

出力イメージ：

```text
3
```

### ToList

LINQ の結果を `List` にしたいときは `ToList` を使います。

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

class Program
{
    static void Main(string[] args)
    {
        int[] numbers = { 1, 2, 3, 4 };
        List<int> evens = numbers.Where(n => n % 2 == 0).ToList();

        Console.WriteLine(evens.Count);
    }
}
```

出力イメージ：

```text
2
```

### 文字列配列と LINQ

文字列の並びにも LINQ を使えます。

```csharp
using System;
using System.Linq;

class Program
{
    static void Main(string[] args)
    {
        string[] names = { "田中", "山田", "高橋" };

        var longNames = names.Where(name => name.Length >= 3);

        foreach (string name in longNames)
        {
            Console.WriteLine(name);
        }
    }
}
```

出力イメージ：

```text
高橋
```

### クラスの一覧と LINQ

クラスの実物が入った `List` にも LINQ を使えます。

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

class User
{
    public string Name { get; set; }
    public int Age { get; set; }
}

class Program
{
    static void Main(string[] args)
    {
        List<User> users = new List<User>
        {
            new User { Name = "田中", Age = 18 },
            new User { Name = "山口", Age = 22 },
            new User { Name = "森", Age = 17 }
        };

        var adults = users.Where(user => user.Age >= 18);

        foreach (User user in adults)
        {
            Console.WriteLine(user.Name);
        }
    }
}
```

出力イメージ：

```text
田中
山口
```

### つなげて書く

LINQ は、しぼる、並べる、変えるを続けて書けます。

```csharp
using System;
using System.Linq;

class Program
{
    static void Main(string[] args)
    {
        string[] names = { "tanaka", "yamada", "ito" };

        var result = names
            .Where(name => name.Length >= 5)
            .OrderBy(name => name)
            .Select(name => name.ToUpper());

        foreach (string name in result)
        {
            Console.WriteLine(name);
        }
    }
}
```

出力イメージ：

```text
TANAKA
YAMADA
```

## ラムダ式

### ラムダ式とは

ラムダ式は、短く書いた関数の形です。  
ここでは「その場で使う小さな処理を短く書く方法」と考えれば大丈夫です。

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Console.WriteLine("ラムダ式は短く書いた処理です");
    }
}
```

出力イメージ：

```text
ラムダ式は短く書いた処理です
```

### => の読み方

`=>` は、左に受け取るもの、右に実行する内容を書く形です。  
ここでは「受け取って、その結果こうする」と読むとわかりやすいです。

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Func<int, int> square = x => x * x;
        Console.WriteLine(square(4));
    }
}
```

出力イメージ：

```text
16
```

### 1つの引数

引数が1つだけなら、丸かっこを省略できることがあります。

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Func<string, string> greet = name => "こんにちは、" + name + " さん";
        Console.WriteLine(greet("田中"));
    }
}
```

出力イメージ：

```text
こんにちは、田中 さん
```

### 複数の引数

引数が複数あるときは、丸かっこで囲みます。

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Func<int, int, int> add = (a, b) => a + b;
        Console.WriteLine(add(10, 20));
    }
}
```

出力イメージ：

```text
30
```

### 戻り値のあるラムダ式

計算結果を返すラムダ式は、右側に式を書きます。

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Func<int, bool> isEven = n => n % 2 == 0;

        Console.WriteLine(isEven(4));
        Console.WriteLine(isEven(5));
    }
}
```

出力イメージ：

```text
True
False
```

### 戻り値のないラムダ式

画面に出すだけのような処理では、返す値がない形もあります。

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Action<string> show = text => Console.WriteLine(text);
        show("abc");
    }
}
```

出力イメージ：

```text
abc
```

### Func と Action

- `Func` は、何かを返す
- `Action` は、返さない

と考えれば最初は十分です。

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Func<int, int> doubleValue = x => x * 2;
        Action<int> show = x => Console.WriteLine(x);

        show(doubleValue(5));
    }
}
```

出力イメージ：

```text
10
```

### 文を複数書くラムダ式

右側を波かっこで囲むと、複数行の処理を書けます。

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Action<string> show = text =>
        {
            Console.WriteLine("開始");
            Console.WriteLine(text);
        };

        show("本体");
    }
}
```

出力イメージ：

```text
開始
本体
```

### ラムダ式と LINQ

LINQ の `Where` などで使っていた `n => n % 2 == 0` の形が、ラムダ式です。

```csharp
using System;
using System.Linq;

class Program
{
    static void Main(string[] args)
    {
        int[] numbers = { 1, 2, 3, 4 };
        var result = numbers.Where(n => n >= 3);

        foreach (int number in result)
        {
            Console.WriteLine(number);
        }
    }
}
```

出力イメージ：

```text
3
4
```

### ラムダ式を変数に入れる

ラムダ式そのものを変数に入れて、あとで使うこともできます。

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Func<int, int> triple = x => x * 3;

        Console.WriteLine(triple(7));
    }
}
```

出力イメージ：

```text
21
```

### メソッドとの違い

メソッドは名前を付けて何度も使う部品、ラムダ式はその場で短く書く小さな処理、と考えると使い分けやすいです。

```csharp
using System;

class Program
{
    static int Add(int a, int b)
    {
        return a + b;
    }

    static void Main(string[] args)
    {
        Func<int, int, int> add2 = (a, b) => a + b;

        Console.WriteLine(Add(1, 2));
        Console.WriteLine(add2(1, 2));
    }
}
```

出力イメージ：

```text
3
3
```

---

## 第十五章まとめ

- ラムダ式は、短く書いた処理
- `=>` の左が受け取り、右が処理
- `Func` は返す、`Action` は返さない
- LINQ の条件にもラムダ式が使われる
- その場で短く書きたいときに向いている

## イベント

### イベントとは

イベントは、「何かが起きたことを知らせる仕組み」です。  
ここでは「ボタンが押された」「処理が終わった」などを伝える合図だと考えれば大丈夫です。

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Console.WriteLine("イベントは起きたことを知らせる仕組みです");
    }
}
```

出力イメージ：

```text
イベントは起きたことを知らせる仕組みです
```

### delegate

イベントの前に、まず「あとで呼べる処理の型」が必要です。  
そのための書き方が `delegate` です。ここでは「処理の型を作る」と考えれば十分です。

```csharp
using System;

delegate void MessageHandler();

class Program
{
    static void Main(string[] args)
    {
        Console.WriteLine("delegate を使います");
    }
}
```

出力イメージ：

```text
delegate を使います
```

### event

イベントとして外から登録できる形にするには `event` を使います。

```csharp
using System;

delegate void AlarmHandler();

class Alarm
{
    public event AlarmHandler Ring;
}

class Program
{
    static void Main(string[] args)
    {
        Console.WriteLine("event を使って知らせます");
    }
}
```

出力イメージ：

```text
event を使って知らせます
```

### イベントを登録する

起きたときに動かしたい処理を、イベントに登録します。

```csharp
using System;

delegate void AlarmHandler();

class Alarm
{
    public event AlarmHandler Ring;

    public void Start()
    {
        if (Ring != null)
        {
            Ring();
        }
    }
}

class Program
{
    static void OnRing()
    {
        Console.WriteLine("鳴りました");
    }

    static void Main(string[] args)
    {
        Alarm alarm = new Alarm();
        alarm.Ring += OnRing;
        alarm.Start();
    }
}
```

出力イメージ：

```text
鳴りました
```

### 複数登録

イベントには、複数の処理を登録できます。

```csharp
using System;

delegate void AlarmHandler();

class Alarm
{
    public event AlarmHandler Ring;

    public void Start()
    {
        if (Ring != null)
        {
            Ring();
        }
    }
}

class Program
{
    static void ShowA()
    {
        Console.WriteLine("A");
    }

    static void ShowB()
    {
        Console.WriteLine("B");
    }

    static void Main(string[] args)
    {
        Alarm alarm = new Alarm();
        alarm.Ring += ShowA;
        alarm.Ring += ShowB;
        alarm.Start();
    }
}
```

出力イメージ：

```text
A
B
```

### 登録を外す

もう動かしたくない処理は外せます。

```csharp
using System;

delegate void AlarmHandler();

class Alarm
{
    public event AlarmHandler Ring;

    public void Start()
    {
        if (Ring != null)
        {
            Ring();
        }
    }
}

class Program
{
    static void ShowA()
    {
        Console.WriteLine("A");
    }

    static void Main(string[] args)
    {
        Alarm alarm = new Alarm();
        alarm.Ring += ShowA;
        alarm.Ring -= ShowA;
        alarm.Start();
        Console.WriteLine("終わり");
    }
}
```

出力イメージ：

```text
終わり
```

### ラムダ式で登録する

イベントは、メソッド名だけでなくラムダ式でも登録できます。


### 引数つきイベント

知らせるだけでなく、いっしょに情報を渡したいこともあります。

```csharp
using System;

delegate void MessageHandler(string message);

class Sender
{
    public event MessageHandler Sent;

    public void Send()
    {
        if (Sent != null)
        {

}

class Program
{
    static void ShowMessage(string message)
    {
        Console.WriteLine(message);
    }

    static void Main(string[] args)
    {
        Sender sender = new Sender();
        sender.Sent += ShowMessage;
        sender.Send();
    }
}
```

出力イメージ：

```text
送信しました
```

### EventHandler

C# には、イベントでよく使う型があらかじめ用意されています。  
その1つが `EventHandler` です。

```csharp
using System;

class TimerLike
{
    public event EventHandler Tick;

    public void Start()
    {
        if (Tick != null)
        {
            Tick(this, EventArgs.Empty);
        }
    }
}

class Program
{
    static void Main(string[] args)
    {
        TimerLike timer = new TimerLike();
        timer.Tick += (sender, e) => Console.WriteLine("Tick");
        timer.Start();
    }
}
```

出力イメージ：

```text
Tick
```

### null 確認

まだ誰も登録していないときは、そのまま呼ぶと困るので確認することがあります。

```csharp
using System;

delegate void AlarmHandler();

class Alarm
{
    public event AlarmHandler Ring;

    public void Start()
    {
        if (Ring == null)
        {
            Console.WriteLine("まだ登録がありません");
            return;
        }

        Ring();
    }
}

class Program
{
    static void Main(string[] args)
    {
        Alarm alarm = new Alarm();
        alarm.Start();
    }
}
```

出力イメージ：

```text
まだ登録がありません
```

### イベントの流れ

イベントは、

- 先に登録する
- 何かが起きる
- 登録された処理が動く

という流れで読むと理解しやすいです。

```csharp
using System;

delegate void NoticeHandler();

class Notifier
{
    public event NoticeHandler Noticed;

    public void Run()
    {
        Console.WriteLine("途中の処理");

        if (Noticed != null)
        {
            Noticed();
        }
    }
}

class Program
{
    static void Main(string[] args)
    {
        Notifier notifier = new Notifier();
        notifier.Noticed += () => Console.WriteLine("通知を受け取りました");
        notifier.Run();
    }
}
```

出力イメージ：

```text
途中の処理
通知を受け取りました
```

- `event` で登録用の窓口を作る
- `+=` で登録し、`-=` で外せる
- ラムダ式でも登録できる
- 先に登録してから、起きたときに呼ばれる流れで読むとわかりやすい
