# ls(1) — ディレクトリ内容を一覧する

`ls` は「ファイル/ディレクトリの一覧」を出す基本コマンドです。
運用では `-l`（詳細）と `-h`（人間サイズ）と `-t`（時刻順）を軸に、
「いま何がある？」「いつ変わった？」「誰の権限？」を素早く見るのが目的になります。

## まず結論：よく使うコマンド

```bash
# 1) 詳細（権限/所有者/サイズ/時刻）
ls -l

# 2) 人間サイズ（MiB/GiB）
ls -lh

# 3) 時刻順（新しい順）で見る（ログやデプロイ直後に便利）
ls -lt

# 4) 逆順（古い順）
ls -ltr

# 5) 隠しファイルも含めて見る（. で始まる）
ls -la

# 6) ディレクトリそのものを一覧（中身ではなく）
ls -ld /etc /var/log

# 7) 1行に1つ（スクリプト向け）
ls -1

# 8) サイズで並び替え（大きい順）
ls -lSh

# 9) 再帰（ディレクトリ配下も）
ls -lR

# 10) SELinux context を見る（トラブルシュートで重要）
ls -lZ /var/www
```

## SYNOPSIS（書式）

```text
ls [OPTION]... [FILE]...
```

- 引数なしだとカレントディレクトリ
- FILE にディレクトリを渡すと「その中身」を出します
- ディレクトリ自体の情報が欲しいときは `-d`（後述）

## `ls -l` の読み方（最初にここ）

`ls -l` はだいたい次の列が出ます（環境により多少違います）。

- 先頭 1 文字: 種類（`-`=通常ファイル、`d`=ディレクトリ、`l`=symlink など）
- 次の 9 文字: パーミッション（`rwxr-x---` など）
- 所有者 / グループ
- サイズ
- 日時
- 名前

`-h` を付けるとサイズが読みやすくなります（例: `1.2K`, `34M`）。

## よく使うオプション（運用優先）

### 隠しファイル：`-a` / `-A`

```bash
ls -a
ls -A
```

- `-a`: `.` と `..` も含めて全部
- `-A`: `.` と `..` は除外（運用ではこっちが見やすいことも多い）

### 詳細：`-l` と派生

```bash
ls -l
ls -lh
ls -l --full-time
```

- `-l`: 詳細
- `-h`: 人間サイズ（`-l` とセットで使うことが多い）
- `--full-time`: 時刻をより詳細に（証跡に便利）

### 並び替え：`-t`（時刻）/ `-S`（サイズ）/ `-X`（拡張子）

```bash
ls -lt      # 新しい順
ls -ltr     # 古い順（-r で逆順）
ls -lSh     # 大きい順
ls -lv      # バージョンっぽい数字順（例: file2 < file10）
```

### ディレクトリそのもの：`-d`

```bash
# /var/log の中身ではなく /var/log そのものを見たい
ls -ld /var/log
```

### 再帰：`-R`

```bash
ls -lR /etc
```

大量に出るので、運用では対象を絞るか、`find` と組み合わせる方が扱いやすいことも多いです。

### 表示をスクリプト向けに：`-1` / `-Q` / `--quoting-style`

```bash
ls -1
ls -1Q
```

- `-1`: 1行1件
- `-Q`: 名前を `"..."` で囲む（空白があるときに視認しやすい）

注意：スクリプトで厳密に処理する用途は、`ls` より `find -print0` 等の方が安全なことが多いです。

### シンボリックリンク：`-L` / `-H`

- `-L`: symlink を辿った先の情報を表示
- `-H`: コマンドラインで指定した symlink だけ辿る

運用では「リンクそのものの情報が欲しい」ことも多いので、**むやみに `-L` を付けない**のが無難です。

### SELinux context：`-Z`

```bash
ls -lZ /var/www
```

SELinux が絡むトラブル（アクセス拒否など）では `-Z` が重要な手掛かりになります。

## 事故りポイント（ls でよくやる）

- **`ls -l /path/dir` が「中身」を出してしまう**
  - ディレクトリ自体を見たいなら `ls -ld /path/dir`
- **ファイル名に空白があり、後段コマンドで壊れる**
  - 見やすさなら `-Q`、機械処理なら `find -print0` を検討
- **サイズの単位（1000/1024）が混乱する**
  - `-h` は読みやすさ優先。厳密なバイト数が必要なら別手段も検討
- **色や装飾が邪魔**
  - `--color=never`（必要なら）

## 小ネタ：`ls` の結果を `less` で読む

```bash
ls -lSh /var/log | less -S
ls -lZ /var/www | less -S
```

長い行を折り返さずに見たいときは `less -S` が便利です。
