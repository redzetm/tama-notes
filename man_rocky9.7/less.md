# less(1) — ページャ（スクロール/検索しながら読む）

`less` は「長いテキストを、スクロール/検索しながら読む」ためのページャです。
`man` や `journalctl` が内部で `less` を呼ぶことも多く、Linux運用では必須級の道具です。

ポイントは次の 3 つです。

- **移動**（上下/ページ/先頭末尾）
- **検索**（`/` と `n`/`N`）
- **表示調整**（色・折り返し・行番号）

## まず結論：よく使うコマンド

```bash
# 1) まずは普通に読む
less /var/log/messages

# 2) 色付き出力（ANSIカラー）を崩さず読む（推奨）
# 例: journalctl は色付きになることがあります
journalctl -xe | less -R

# 3) 長い行を折り返さずに読む（横スクロール/行頭が揃う）
# 例: JSON, 長い設定行, ss の出力
ss -lntp | less -S

# 4) 行番号を表示して読む（抜粋/報告が楽）
less -N /etc/ssh/sshd_config

# 5) 末尾から読む（ログ調査の定番）
less +G /var/log/messages

# 6) 最初から検索で当てに行く（例: error を探して開始）
less +/error /var/log/messages

# 7) tail -f 相当（ファイル追跡）
# 起動後に less 内で F を押しても同じ
less +F /var/log/messages

# 8) 1画面で収まるなら自動で終了（スクリプトで便利）
less -F README.md

# 9) less を抜けた後も画面を残したい（見比べ用途）
less -X file.txt
```

## SYNOPSIS（書式）

```text
less [OPTION...] [--] [filename]...
```

- ファイルを複数渡せます（`less a b c`）。`less` 内で次/前のファイルへ移動できます。
- 標準入力も読めます（`cmd | less`）。

## まず覚えるキー（最小セット）

### 退出/ヘルプ

- `h` / `H`: ヘルプ
- `q`: 終了

### 移動

- `j` / `Enter`: 1行進む
- `k`: 1行戻る
- `Space` / `f`: 1画面進む
- `b`: 1画面戻る
- `d`: 半画面進む
- `u`: 半画面戻る
- `g`: 先頭へ
- `G`: 末尾へ

### 検索

- `/pattern`: 前方検索
- `?pattern`: 後方検索
- `n`: 次の一致へ
- `N`: 前の一致へ（逆方向）

実務では「`/error` → `n` 連打」が基本形です。

## 便利キー（現場で効く）

- `=` / `^G`: いま見ているファイル名などの情報表示
- `R`: ファイルを読み直す（ログが増えた時のリロード）
- `F`: 末尾追跡（`tail -f` 的）
- `ESC-F`: 追跡しつつ「検索に当たったら止まる」
- `m<letter>`: マーク（しおり）を付ける（例: `ma`）
- `'<letter>`: マークへ戻る（例: `'a`）
- `''`: 直前位置へ戻る（往復）

### 複数ファイルを渡したときの移動

- `:n`: 次のファイル
- `:p`: 前のファイル
- `:d`: 今のファイルをリストから削除（「もう見ない」）
- `:e file`: 別のファイルを開く

## 重要オプション（覚える価値が高い）

### 色を壊さない：`-R`（おすすめ）

- `-R`, `--RAW-CONTROL-CHARS`
  - ANSI カラー（例: `\x1b[31m`）など「一部の制御シーケンス」を解釈して、**色付きのまま表示**します。

注意：似たオプションに `-r` がありますが、挙動が強く（より多くの制御文字を通す）**ターミナルが壊れたように見える事故**につながりやすいので、まずは `-R` を使うのが安全です。

### 長い行を折り返さない：`-S`

- `-S`, `--chop-long-lines`
  - 折り返しをしない（横に切る）
  - ログや表形式の出力、JSON、`ss` の出力で読みやすくなります

横スクロールは `ESC-)` / `ESC-(`（環境により矢印キー）で行えます。

### 行番号：`-N`

- `-N`, `--LINE-NUMBERS`
  - 行番号を表示します
  - 抜粋するときに「どこを見たか」の根拠になり便利です

### 大文字小文字：`-i` / `-I`

- `-i`, `--ignore-case`
  - 検索パターンに大文字が含まれない時だけ大小無視
- `-I`, `--IGNORE-CASE`
  - 常に大小無視

### 起動直後に末尾へ：`+G` / `-e`

```bash
# 末尾から読む
less +G file

# journalctl の「-e（末尾ジャンプ）」は pager（less）前提
# 例: sudo journalctl -u nginx -b -e
```

### 起動直後に検索：`+/pattern` / `-p pattern`

```bash
# 最初に検索して、当たった位置から表示
less +/error file

# -p でも同様（挙動が違う環境もあるので +/ が分かりやすい）
less -p error file
```

## less 実務テンプレ（調査でよく使う組み合わせ）

```bash
# systemd ログを色付きのまま閲覧
sudo journalctl -u sshd -b -e | less -R

# 大量ログをざっくり眺めて検索
sudo journalctl -u nginx -b --no-pager | less

# 設定ファイルを行番号付きで読む
less -N /etc/nginx/nginx.conf

# 1行が長い出力を折り返さずに読む
nmcli -t -f NAME,UUID,TYPE,DEVICE connection show | less -S

# 末尾追跡しつつ、該当行が出たら止めたい（error に当たったら止める）
less +F /var/log/messages
# 追跡中に ESC-F を使うには、先に /error で検索しておく
```

## 起動中にオプションを切り替える（地味に便利）

`less` 実行中に次のように入力すると、表示オプションを切り替えられます。

- `-S`: 折り返し有無をトグル
- `-N`: 行番号のトグル
- `-i`: 大文字小文字のトグル

（`-` のあとに 1 文字のフラグを入れるイメージです。`--option-name` でも切り替え可能です。）

## 事故りポイント（よくあるハマり）

- **色付き出力が `^[` だらけになる**
  - `less -R` を使う（`-r` ではなく `-R` から）
- **長い行が勝手に折り返されて読みづらい**
  - `-S` を付ける、または実行中に `-S` でトグル
- **複数ファイルを開いたのに次へ進めない**
  - `:n`（次）と `:p`（前）
- **追跡（F）で止められない**
  - `Ctrl-C` で追跡を止める（環境によりキーは異なる場合あり）
- **シェルコマンドが実行できてしまうのが怖い**
  - `less` には `!cmd` のような機能があります。運用端末のポリシーに従い、不要なら権限/設定（`LESSSECURE` 等）を検討します。

## 環境変数（触ると便利になるやつ）

`less` は環境変数で挙動を変えられます（環境依存あり）。

```bash
# よく使うオプションをデフォルト化（例）
export LESS='-R -S -M'

# 現状確認
echo "$LESS"
echo "$LESSOPEN"
echo "$LESSCLOSE"
```

- `LESS`: デフォルトオプション（毎回 `-R -S` を打つのを省ける）
- `LESSOPEN` / `LESSCLOSE`: 前処理/後処理（圧縮ファイルを透過的に見せる等。多くの環境で設定済み）

## 参考：チートシート（`h` で見られる）

忘れたら `less` 内で `h` を押すのが最短です。
