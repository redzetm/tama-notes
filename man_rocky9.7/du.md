# du(1) — ディレクトリ使用量の見積り

`du` は、指定したファイル/ディレクトリの **ディスク使用量**を（基本は再帰的に）集計します。

- 「どのディレクトリが太ってる？」
- 「ログやキャッシュがどこを食っている？」
- 「削る前に、影響が大きい場所から当たりを付けたい」

…の時に使います。

## まず結論：よく使うコマンド

```bash
# まずはこれ（指定ディレクトリの合計だけ、見やすい単位）
du -sh /var

# 直下だけ一覧（どこが太いか）
du -h --max-depth=1 /var

# カレント直下を合計で一覧（* を使う）
du -sh *

# 同一ファイルシステム内だけ（/ を対象にした時の "別FS" を避ける）
du -xh --max-depth=1 /

# 大きい順に見たい（上位だけ）
du -ah /var | sort -h | tail -n 20

# 除外したい（パターンはシェルパターン）
du -h --max-depth=1 --exclude='*.log' /var

# 合計（grand total）を付ける
# ※ --max-depth などと併用する時に便利
du -ch --max-depth=1 /var
```

## SYNOPSIS（書式）

```text
du [OPTION]... [FILE]...
du [OPTION]... --files0-from=F
```

- `FILE` 省略時はカレントディレクトリを対象
- ディレクトリは再帰的に集計されます

## 出力の見方（最低限）

`du` の出力は基本的に「サイズ + パス」です。

- `-h` を付けると単位が読みやすくなります
- `-s` を付けると「引数ごとに合計1行」になります
- `--max-depth=N` を付けると「深さNまで」の合計を出せます（運用で便利）

## よく使うオプション（運用で効く範囲）

### 単位

- `-h, --human-readable`
  - 見やすい単位（1024基準）
- `--si`
  - 1000基準
- `-B, --block-size=SIZE`
  - 単位固定（例：`-BM`）

### 集計の粒度

- `-s, --summarize`
  - 引数ごとの合計だけ（1行）
- `-d, --max-depth=N`
  - 深さ N までの合計を表示（`--max-depth=0` は `-s` 相当）
- `-a, --all`
  - ディレクトリだけでなくファイルも出力する（`sort` したい時に便利）

### 「見た目のサイズ」か「ディスク使用量」か

- `--apparent-size`
  - 見た目（ファイルサイズ）を合計
- （デフォルト）
  - ディスク上の使用量を合計

```bash
# 見た目サイズ（例：スパースファイルが絡む時の比較）
du -sh --apparent-size somefile

# ディスク使用量（実際に食っている量）
du -sh somefile
```

### ファイルシステムをまたがない

- `-x, --one-file-system`
  - 別ファイルシステム配下へ入らない（`/` を調べる時の定番）

### シンボリックリンク

- `-P, --no-dereference`（デフォルト）
  - シンボリックリンクを辿らない
- `-L, --dereference`
  - すべてのシンボリックリンクを辿る（意図がない限りは避ける）
- `-D, --dereference-args`
  - コマンドラインに書いた引数のリンクだけ辿る

### 除外

- `--exclude=PATTERN`
- `-X, --exclude-from=FILE`

注意：`PATTERN` は **正規表現ではなくシェルパターン**です（例：`*.o`）。

### inode を見たい

- `--inodes`
  - ブロック使用量ではなく inode 使用量を表示

## よくある調査レシピ

### 1) まず合計だけ

```bash
du -sh /var
```

### 2) 直下のどれが太い？

```bash
du -h --max-depth=1 /var
```

### 3) 大きいファイル/ディレクトリ上位を見たい

```bash
du -ah /var | sort -h | tail -n 20
```

### 4) `/` を見たいが、別ファイルシステムは混ぜたくない

```bash
du -xh --max-depth=1 /
```

## 事故りやすい点（短く）

- `du` のデフォルトは「ディスク使用量」で、`--apparent-size` は別物
  - スパースファイル等では見た目と実使用量が大きくズレます
- `du /` は別ファイルシステムまで入って見え方が変わる
  - まず `-x` を付けると事故が減ります
- `--exclude` は正規表現ではない
  - `*.log` のようなシェルパターンです
