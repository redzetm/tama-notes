# scanf(3) — 標準入力から書式に従って読み取る

`scanf` は、C言語の標準ライブラリが提供する入力関数です。
標準入力からデータを読み取り、書式文字列に従って整数や文字列などへ変換して変数に格納します。

ただし、`scanf` は便利な反面、入力の食い残しやバッファあふれを起こしやすく、初心者がつまずきやすい関数でもあります。

## まず結論：scanf は何者か

- 分類：標準ライブラリ関数
- `man` の分類：セクション 3 相当
- ヘッダファイル：`<stdio.h>`
- 標準入力から値を読み取り、変数へ格納する関数
- システムコールではない
- 演算子ではない

## `scanf` と `read` の違い

### `scanf` は高レベル入力

- 入力文字列を整数や文字列へ変換する
- 空白文字の扱いをある程度自動で行う
- 入力形式を `%d` や `%s` で指定する

### `read` は低レベルI/O

- fd から生のバイト列を読む
- 文字列変換は自分で行う
- 何バイト読むかを明示する

つまり、

- `scanf` は「読み取って解釈する」
- `read` は「そのまま読む」

という違いがあります。

## SYNOPSIS

```c
#include <stdio.h>

int scanf(const char *format, ...);
```

## ヘッダファイル

```c
#include <stdio.h>
```

## 引数

- `format`
  - 入力の読み取り方を指定する書式文字列
  - `%d`、`%lf`、`%s` などを使う
- `...`
  - 読み取った結果を書き込む変数のアドレス
  - 例えば `int x; scanf("%d", &x);` のように使う

## 戻り値

- 成功時
  - 正しく代入できた項目数を返す
- 入力失敗時
  - 期待した形式で読めなければ、その時点までの代入数を返す
- 入力終端や読取失敗時
  - `EOF` を返すことがある

ここで重要なのは、`scanf` は「読んだ文字数」ではなく「代入できた項目数」を返すという点です。

## 最小サンプル

```c
#include <stdio.h>

int main(void)
{
    int age;

    printf("age? ");
    if (scanf("%d", &age) != 1) {
        printf("input error\n");
        return 1;
    }

    printf("age = %d\n", age);
    return 0;
}
```

## 典型例

### 1. 整数を1つ読む

```c
int x;

if (scanf("%d", &x) == 1) {
    printf("x = %d\n", x);
}
```

`x` そのものではなく、`&x` を渡すのが重要です。
`scanf` は変数へ書き込むので、アドレスが必要です。

### 2. 複数の値を読む

```c
int a;
int b;

if (scanf("%d %d", &a, &b) == 2) {
    printf("a=%d b=%d\n", a, b);
}
```

戻り値が 2 であることを確認すれば、両方読めたと分かります。

### 3. 文字列を読む

```c
char name[32];

if (scanf("%31s", name) == 1) {
    printf("name = %s\n", name);
}
```

`%s` で読むときは、幅制限を付けるのが非常に重要です。

## よく使う変換指定子

- `%d`
  - `int` を読む
- `%u`
  - `unsigned int` を読む
- `%ld`
  - `long` を読む
- `%lf`
  - `double` を読む
- `%c`
  - 1文字を読む
- `%s`
  - 空白までの文字列を読む

## 注意点

### 1. 変数そのものではなくアドレスを渡す

```c
int x;
scanf("%d", &x);   /* 正しい */
scanf("%d", x);    /* 間違い */
```

`scanf` は読み取った値を書き込むので、通常は `&` を付けてアドレスを渡します。

ただし配列名はもともと先頭要素へのポインタとして使われるため、文字列入力では普通 `&` を付けません。

```c
char name[32];
scanf("%31s", name);
```

### 2. `%s` は幅制限を付けないと危険

```c
char name[8];
scanf("%s", name);      /* 危険 */
scanf("%7s", name);     /* まだまし */
```

入力が長すぎると配列をはみ出して書き込み、バッファオーバーフローになります。

### 3. 改行が入力バッファに残る問題

例えば、

```c
int x;
char ch;

scanf("%d", &x);
scanf("%c", &ch);
```

とすると、2つ目の `%c` が前の Enter の改行を読んでしまうことがあります。

この場合は、

```c
scanf(" %c", &ch);
```

のように先頭へ空白を入れて、余分な空白文字を読み飛ばすことがあります。

### 4. 戻り値を確認しないと壊れやすい

```c
int x;
scanf("%d", &x);
```

これだけだと、入力失敗時に `x` が期待どおりに入っていない可能性があります。
`scanf` は戻り値確認がほぼ必須です。

### 5. 行単位入力には向かないことが多い

`scanf` は書式入力には便利ですが、対話的な入力や空白を含む文字列処理では扱いづらいです。

例えば氏名や文章のように空白を含む入力では、`%s` だと最初の空白で止まります。
そのため、実務では `fgets` で1行読み、必要なら `sscanf` で解釈する流れのほうが安全なことが多いです。

## `scanf` と `fgets` の使い分け

### `scanf` が向く場面

- 数字を決まった書式で簡単に読みたい
- 学習用の小さなサンプル
- 空白区切りの入力を素早く処理したい

### `fgets` が向く場面

- 1行まるごと安全に読みたい
- 入力長を制限したい
- 空白を含む文字列を扱いたい
- 入力エラー処理を丁寧にしたい

初心者向けには、文字列入力は `scanf("%s", ...)` より `fgets` のほうが事故りにくいです。

## まず覚える形

最初は次の2つを確実に覚えるとよいです。

```c
scanf("%d", &x);
scanf("%31s", name);
```

そして実際には、必ず戻り値も確認します。

```c
if (scanf("%d", &x) != 1) {
    /* エラー処理 */
}
```

## 関連API

- `printf`
  - 出力側の代表的な標準ライブラリ関数
- `fgets`
  - 1行入力を安全に扱いやすい
- `sscanf`
  - 文字列を入力元として書式解析する
- `read`
  - 低レベルI/O

## まとめ

- `scanf` は標準ライブラリ関数
- 標準入力から書式に従って値を読む
- 戻り値は「代入できた項目数」
- `%s` では幅制限が重要
- 戻り値確認をしないと壊れやすい
- 行単位入力では `fgets` のほうが安全なことが多い
