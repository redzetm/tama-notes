# puts(3) — 文字列を標準出力へ簡単に出力する

`puts` は、C言語の標準ライブラリが提供する出力関数です。
文字列を標準出力へ出力し、最後に改行文字 `\n` も自動で付けます。

`printf` より機能は少ないですが、単純に1行出したいときには分かりやすく使えます。

## まず結論：puts は何者か

- 分類：標準ライブラリ関数
- `man` の分類：セクション 3 相当
- ヘッダファイル：`<stdio.h>`
- 文字列を標準出力へ出すための関数
- 出力の末尾に改行を自動で付ける

## `puts` と `printf` の違い

### `puts` が向いている場面

- ただ文字列1つを表示したい
- 書式指定は不要
- 末尾に改行を自動で付けてほしい

### `printf` が向いている場面

- 数値や文字列を組み合わせて表示したい
- `%d` や `%s` のような書式指定を使いたい
- 改行を付けるかどうかを自分で制御したい

例えば次の2つは、見た目の結果は似ています。

```c
puts("hello");
printf("hello\n");
```

ただし性格は少し違います。

- `puts` は「文字列を出して改行する」専用に近い
- `printf` は「整形して出力する」汎用関数

## SYNOPSIS

```c
#include <stdio.h>

int puts(const char *s);
```

## ヘッダファイル

```c
#include <stdio.h>
```

## 引数

- `s`
  - 出力したい文字列へのポインタ
  - 末尾はヌル文字 `\0` で終わっている必要がある

## 戻り値

- 成功時
  - 非負の値を返す
- 失敗時
  - `EOF` を返す

`printf` のように「何文字出したか」を返す用途ではありません。
成功か失敗かを大まかに判定するイメージです。

## 最小サンプル

```c
#include <stdio.h>

int main(void)
{
    puts("hello");
    puts("world");
    return 0;
}
```

出力例：

```text
hello
world
```

## 典型例

### 1. デバッグ用に1行だけ出す

```c
#include <stdio.h>

int main(void)
{
    puts("start");
    return 0;
}
```

`printf("start\n");` でも同じようなことはできますが、固定文字列1つなら `puts` のほうが単純です。

### 2. 複数の固定メッセージを順に出す

```c
#include <stdio.h>

int main(void)
{
    puts("menu:");
    puts("1. open");
    puts("2. save");
    puts("3. exit");
    return 0;
}
```

## 注意点

### 1. 改行が自動で付く

これが `puts` の一番大事な特徴です。

```c
puts("hello");
```

は、概念的には次に近い出力になります。

```text
hello\n
```

そのため、改行を付けたくない場面には向きません。

### 2. 書式指定はできない

次のようなことはできません。

```c
int x = 10;
puts("x = %d");
```

このコードは `%d` を展開せず、そのまま文字として出力します。
数値を埋め込みたいなら `printf` を使います。

```c
int x = 10;
printf("x = %d\n", x);
```

### 3. 文字列が `NULL` のときは危険

```c
char *p = NULL;
puts(p);
```

これは未定義動作になり得ます。
表示する前に、有効な文字列ポインタかを確認するほうが安全です。

### 4. バイナリデータには向かない

`puts` はヌル終端文字列を前提にしています。
途中に `\0` を含むデータや、長さを別管理するバイナリ列には向きません。

## `puts` と `write` の違い

- `puts` は標準ライブラリ関数
- `write` は低レベルのシステムコール系API
- `puts` は文字列の末尾までを扱い、最後に改行も足す
- `write` は「何バイト書くか」を呼び出し側が明示する

つまり、`puts` は人間向けの簡易表示に向き、`write` は低レベルI/O制御に向きます。

## まず覚える形

最初はこれだけで十分です。

```c
puts("hello");
```

固定文字列を1行表示したいときは `puts`、数値や変数を混ぜたいときは `printf` と覚えると整理しやすいです。

## 関連API

- `printf`
  - 書式付きで出力できる
- `fputs`
  - 指定したストリームへ文字列を出力する
- `fprintf`
  - 指定したストリームへ書式付き出力を行う
- `write`
  - 低レベルI/O

## まとめ

- `puts` は標準ライブラリ関数
- `printf` より単純な文字列出力に向く
- 改行を自動で付ける
- 書式指定はできない
- 数値や変数を混ぜたいなら `printf` を使う
