# printf(3) — 標準出力へ整形して出力する

`printf` は、C言語の標準ライブラリが提供する出力関数です。
書式文字列（format string）に従って値を文字列化し、標準出力へ書き出します。

このページでは、`printf` が

- 標準ライブラリ関数なのか
- システムコールなのか
- 演算子なのか

を最初に整理したうえで、実際の使い方をまとめます。

## まず結論：printf は何者か

- 分類：標準ライブラリ関数
- `man` の分類：セクション 3 相当
- ヘッダファイル：`<stdio.h>`
- システムコールではない
- 演算子ではない

### 似たものとの違い

#### 1. `printf` は標準ライブラリ関数

- Cプログラムから「関数呼び出し」として使う
- 実体は通常 `libc`（glibc など）が提供する
- 内部では必要に応じて `write` などを使って出力することがある

#### 2. `write` はシステムコール系

- `write` はファイルディスクリプタに対してバイト列を書き込む低レベルI/O
- `printf` は「整数を文字列に変換する」「書式を解釈する」などの高レベル処理を含む
- つまり、`printf` と `write` は役割が違う

#### 3. `sizeof` は演算子

- `sizeof(x)` は見た目が関数っぽいが、関数ではなく演算子
- ヘッダファイルは不要
- システムコールでも標準ライブラリ関数でもない
- 多くの場合、サイズはコンパイル時に決まる

混同しやすい3つを並べると、次のようになります。

| 名前 | 種類 | 例 |
| --- | --- | --- |
| `printf` | 標準ライブラリ関数 | 文字列や数値を整形して表示する |
| `write` | システムコール系API | fdに生のバイト列を書き込む |
| `sizeof` | 演算子 | 型やオブジェクトの大きさを調べる |

## SYNOPSIS

```c
#include <stdio.h>

int printf(const char *format, ...);
```

## ヘッダファイル

```c
#include <stdio.h>
```

## 引数

- `format`
  - 書式文字列
  - そのまま表示する文字と、`%d` や `%s` などの変換指定子を混在できる
- `...`
  - 書式文字列に対応する可変個引数
  - 例えば `%d` なら `int`、`%s` なら文字列へのポインタを渡す

## 戻り値

- 成功時
  - 出力した文字数を返す
- 失敗時
  - 負の値を返す

単に「表示できたか」だけでなく、何文字出力したかが分かる点は重要です。

## 最小サンプル

```c
#include <stdio.h>

int main(void)
{
    int age = 20;

    printf("hello\n");
    printf("age = %d\n", age);

    return 0;
}
```

出力例：

```text
hello
age = 20
```

## よく使う変換指定子

- `%d`
  - `int` を10進整数で表示
- `%u`
  - `unsigned int` を10進整数で表示
- `%ld`
  - `long` を10進整数で表示
- `%zu`
  - `size_t` を表示
- `%c`
  - 1文字を表示
- `%s`
  - 文字列を表示
- `%p`
  - ポインタ値を表示
- `%f`
  - `double` を小数で表示
- `%%`
  - `%` 自体を表示

## 典型例

### 1. 数値と文字列を一緒に表示する

```c
#include <stdio.h>

int main(void)
{
    const char *name = "tama";
    int score = 95;

    printf("name=%s score=%d\n", name, score);
    return 0;
}
```

### 2. `sizeof` と組み合わせる

`sizeof` は演算子ですが、`printf` で表示したくなることがよくあります。

```c
#include <stdio.h>

int main(void)
{
    int values[10];

    printf("array bytes = %zu\n", sizeof(values));
    return 0;
}
```

ここで大事なのは、

- `sizeof(values)` は演算子の結果
- `printf(...)` はその結果を表示するライブラリ関数

という役割分担です。

## エラーと注意点

### 1. `%` に対応する引数の型を合わせる

```c
int x = 10;
printf("%d\n", x);    /* 正しい */
printf("%s\n", x);    /* 間違い */
```

書式指定子と実引数の型がずれると、誤表示だけでなく未定義動作になる可能性があります。

### 2. `size_t` は `%zu` を使う

`sizeof` の結果や `strlen` の戻り値は `size_t` です。
Linux ではたまたま `%lu` で見えてしまう場面もありますが、移植性のため `%zu` を使うほうが正しいです。

### 3. 改行がないと、すぐ表示されないことがある

標準出力はバッファリングされます。
端末に向けた出力では改行で流れることが多いですが、状況によってはすぐ見えません。

```c
printf("hello");
```

これだけだと、実行環境によっては表示タイミングが遅れることがあります。

### 4. ユーザー入力をそのまま書式文字列にしない

```c
char *user_input = "%x %x %x";
printf(user_input);          /* 危険 */
printf("%s", user_input);   /* 安全側 */
```

これは format string vulnerability の典型です。
外から来た文字列は、書式そのものではなく、通常は `%s` で表示します。

## `printf` と `write` の使い分け

### `printf` が向く場面

- 人間向けに読みやすく表示したい
- 整数や文字列を整形して出したい
- デバッグ表示をすぐ書きたい

### `write` が向く場面

- fd を直接扱いたい
- バイナリデータをそのまま書きたい
- 標準I/Oのバッファリングを避けたい
- 低レベルI/Oの挙動を正確に追いたい

## まず覚える形

最初は次の2つをまず確実に使えるようにすると十分です。

```c
printf("hello\n");
printf("x = %d\n", x);
```

そのあとで、

- `%s`
- `%zu`
- `%p`
- フィールド幅や桁数指定

へ広げていくと理解しやすいです。

## 関連API

- `fprintf`
  - 出力先を `stdout` 以外のストリームに変えられる
- `snprintf`
  - 画面ではなくバッファへ整形出力する
- `puts`
  - 文字列を簡単に出す用途では手軽
- `write`
  - 低レベルI/O
- `sizeof`
  - 関数ではなく演算子

## まとめ

- `printf` は標準ライブラリ関数
- システムコールではない
- 演算子でもない
- `sizeof` は関数ではなく演算子
- `printf` は「値を見やすい文字列にして表示する」ための高レベルな出力関数
